Falling Ceil

Falling Ceil is a fast-paced survival game where the player must escape from a continuously falling ceiling. The ceiling accelerates over time, making the game more challenging the longer you survive. The game uses a simple block-based visual design for a clean and retro feel.

🎮 Gameplay

You control a block-shaped player.

A ceiling starts falling slowly from above.

As time increases, the ceiling speeds up.

Your goal: Stay alive as long as possible.

✨ Features
